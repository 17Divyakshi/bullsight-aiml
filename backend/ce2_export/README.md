# BULLSIGHT CE-2 model artifacts

Generated by executing the notebook, not supplied as pretrained models.

## Data convention
Use yfinance `auto_adjust=True` for every ticker in both training and inference.
Adjusted OHLC must be consistent; Volume is excluded from features.
Historical adjusted prices can change after corporate actions.

## FastAPI inference
1. Install requirements.txt in a compatible Python environment.
2. Import `make_features, FEATURES, SEQ_LEN` from feature_engineering.py.
3. Download >=60 adjusted OHLC trading rows (preferably full history); run `make_features`.
4. Read STOCK/model_metadata.json and its `selected_model` and `final_model_file`.
5. For classical selected model, load `selected_final_pipeline.joblib` with joblib and predict from last feature row.
6. For LSTM, load `selected_final_lstm.keras`, `selected_final_feature_scaler.joblib`, and `selected_final_target_scaler.joblib`. Scale the last 30 feature rows; predict and inverse-transform the target.
7. Return ticker, last observed session date, last Close, predicted next observed Close, and model name. Do not invent a trading date.
8. `model_metrics.csv` and `test_predictions.csv` are from the original training-only evaluation models; the selected final model is refitted on train+validation without test labels. Never imply the frozen test metrics are a test of the refitted model.
9. Check `stock_status.csv`; five-stock completion requires all five VERIFIED.

## Backtesting
Signal at feature-day close; next session adjusted Open entry, same-day adjusted Close exit, two-sided transaction costs, flat overnight. Short positions assume frictionless borrowing. `daily_long` is matched intraday benchmark; `buy_hold` carries overnight risk. Not financial advice.

Note: refitted models do not use the held-out test labels, so they can be stale for future forecasting. Run walk-forward validation and later retrain on all available labeled history before production use, with a separate honest out-of-sample evaluation.
